# 1. Project Information

## Development Type

Web Application

## Development Method

Incremental Development

---

# 2. Project Background

Saat ini banyak website portfolio masih menggunakan konten statis sehingga setiap perubahan data harus dilakukan langsung pada source code.

Project ini dibuat untuk mengatasi permasalahan tersebut dengan menyediakan sebuah Content Management System (CMS) sehingga seluruh isi website dapat dikelola melalui dashboard admin tanpa perlu mengubah kode program.

Project ini juga dibuat sebagai media pembelajaran sekaligus tugas pengembangan web menggunakan PHP Native dan MySQL.

---

# 3. Project Goal

Membangun website portfolio modern yang seluruh kontennya dapat dikelola melalui CMS menggunakan PHP Native dan MySQL tanpa perlu mengubah source code.

Website harus:

- Modern
- Responsive
- Mudah digunakan
- Mudah dipelihara
- Aman
- Cepat
- SEO Friendly

---

# 4. Main Objectives

Project ini bertujuan untuk:

- Membuat website portfolio modern.
- Membuat CMS sederhana namun lengkap.
- Mengelola seluruh konten melalui dashboard.
- Mengurangi kebutuhan edit source code.
- Menampilkan data secara dinamis dari database.
- Menjadi project portfolio yang layak dipresentasikan.

---

# 5. Target User

Project ini hanya memiliki satu jenis pengguna.

Administrator

Hak akses:

- Mengelola seluruh isi website
