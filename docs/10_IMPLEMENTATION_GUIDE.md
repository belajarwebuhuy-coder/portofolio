# 7. Rules for Claude / Lovable

AI wajib.

- Membaca dokumentasi terlebih dahulu.
- Mengikuti Feature List.
- Mengikuti Database Design.
- Mengikuti UI Guidelines.
- Mengikuti Coding Standards.

AI dilarang.

- Mengubah database.
- Mengubah struktur folder.
- Mengubah nama field.
- Mengubah nama tabel.
- Menambahkan fitur baru.

Tanpa persetujuan.
